# User Manual

## Review a Document

1. Open the Mr Money AI web application.
2. Upload a supported document or paste text into the editor.
3. Select `Run Review`.
4. Review the publication readiness score, quality metrics, findings, and action plan.
5. Export the report as PDF, DOCX, HTML, Markdown, or JSON.

## Reading Scores

- Publication readiness: combined writing, citation, accessibility, compliance, security, fact-checking, and originality score.
- Writing quality: grammar, readability, style, structure, tone, and consistency.
- Originality: local internal originality score.
- Similarity: local internal repetition and similarity score.
- AI-writing indicator: probabilistic writing-pattern signal, not proof of AI authorship.
- AI analysis confidence: confidence in the indicator based largely on available text length and evidence quality.

## Findings

Each finding includes:

- severity
- category
- agent
- confidence
- message
- recommendation
- optional excerpt

High and critical findings should be reviewed before publication.

## Supported Formats

DOCX, PDF, TXT, RTF, ODT, Markdown, HTML, LaTeX, EPUB, CSV, XLSX, PPTX, JSON, XML.

Scanned PDFs require OCR in production deployments.

## Responsible Use

Use Mr Money AI as review support. Do not use AI-writing indicators as the only basis for academic misconduct, employment, or disciplinary decisions.
