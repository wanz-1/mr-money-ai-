# API Documentation

Base URL for local development:

```text
http://127.0.0.1:8765
```

## Health

`GET /health`

Response:

```json
{
  "status": "ok",
  "service": "humanproof-ai"
}
```

## Capabilities

`GET /api/capabilities`

Returns supported file formats, report formats, available agent families, and the analysis mode.

## Create Review

`POST /api/reviews`

Text payload:

```json
{
  "filename": "proposal.md",
  "contentType": "text/markdown",
  "content": "# Proposal\nResearch shows that 44 percent..."
}
```

Base64 file payload:

```json
{
  "filename": "proposal.docx",
  "contentType": "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
  "contentBase64": "UEsDB..."
}
```

Response:

```json
{
  "reviewId": "uuid",
  "createdAt": "2026-07-13T07:00:00Z",
  "document": {
    "filename": "proposal.md",
    "file_format": "md",
    "content_type": "text/markdown",
    "size_bytes": 1280,
    "extracted_at": "2026-07-13T07:00:00Z"
  },
  "summary": "Reviewed 200 words...",
  "scores": {
    "publication_readiness": 88.0,
    "writing_quality": 91.0,
    "originality": 100.0,
    "ai_writing_indicator": 22.0,
    "ai_analysis_confidence": 42.0
  },
  "findings": [],
  "agents": [],
  "limitations": [],
  "actionPlan": [],
  "revisionHistory": []
}
```

## Retrieve Review

`GET /api/reviews/{reviewId}`

Returns the same report payload generated by `POST /api/reviews`.

## Export Report

`GET /api/reviews/{reviewId}/reports/{format}`

Supported formats:

- `json`
- `md`
- `html`
- `docx`
- `pdf`

The response includes a `Content-Disposition` attachment filename.

## Error Shape

```json
{
  "error": "Review not found."
}
```

## Production API Requirements

The local server intentionally omits authentication. Production deployments must add:

- TLS at the edge and service mesh encryption internally
- OAuth2/OIDC SSO
- MFA enforcement policy
- organization and workspace authorization
- RBAC checks on every document and review endpoint
- request size limits and malware scanning
- immutable audit events for upload, read, export, delete, and permission changes
- webhook signing for outbound events
